                def make_greeter(greeting)
                    # Returns a function that "remembers" `greeting`
                    lambda { |name| "#{greeting}, #{name}!" }
                end

                friendly_greeter = make_greeter("Hey there")
                # `friendly_greeter` holds onto "Hey there"

                puts friendly_greeter.call("37signals") # => Hey there, Beau!

Closures are deceptively simple. They are often described as a function wrapping a function, but that's hard for us to really understand until we use them. Even then! I used them in a template-like fashion for many projects before really appreciating their power. Closures offer reusability and flexability in such a nice little package. They are simple and powerful. All of my programming AHA! moments speak to me, but this one stands out.
